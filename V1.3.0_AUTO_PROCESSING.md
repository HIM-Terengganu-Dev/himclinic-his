## 🔐 Technical Implementation

### READ-Only Order Processing
```typescript
// No WRITE to orders - pure READ
const orders = await getOrders({
  status: 'processing',           // Only processing orders
  after: lastCheckTime,            // Only new orders
  per_page: 100
});

// Process each order
for (const order of orders) {
  // Deduct stock automatically
  processOrder(order);
}

// Update timestamp for next check
lastCheckTime = new Date();
```

### Duplicate Prevention
1. **Time-based filtering** - Only orders after last check
2. **In-memory tracking** - Per serverless instance
3. **1-hour lookback** - On instance start for safety
4. **Status reliance** - Your other system moves to "completed"

## ⚠️ Important Notes

### Timing
- Orders processed within **30 seconds** (when auto-refresh ON)
- If dashboard closed, processes all missed orders on next open
- Works even after weeks of inactivity

### Order Status Dependency
- **Requires:** Your other system changes order status to "completed"
- **Why:** This prevents duplicate processing
- **Your workflow:** This system deducts stock → Your system fulfills → Status changes

### Stock Updates
- **Single SKUs:** Written to WooCommerce ✅
- **Combo SKUs:** Calculated and written to WooCommerce ✅
- **Orders:** READ-only, never written to ✅

## 🔍 Safety Features

### 1. Insufficient Stock Handling
```
If order requires more stock than available:
├─ Logs warning
├─ Skips that item
├─ Continues with other items
└─ Shows in console for manual review
```

### 2. Duplicate Prevention
```
Time-based filtering:
├─ Only process orders after last check
├─ 1-hour lookback on instance start
└─ Relies on status changes by other system
```

### 3. Error Handling
```
If processing fails:
├─ Logs error with order ID
├─ Continues with next order
└─ System remains operational
```

## 🔧 Configuration

### Adjust Auto-Refresh Interval
Edit `app/page.tsx` line ~45:
```typescript
}, 30000); // Change to 10000 for 10s, 60000 for 1 min
```

### Adjust Order Check Lookback
Edit `app/api/inventory/route.ts` line ~14:
```typescript
let lastOrderCheckTime = new Date(Date.now() - 60 * 60 * 1000);
// Change 60 * 60 * 1000 (1 hour) to your preferred lookback
```

### Recently Processed Orders Limit
Edit `app/api/inventory/route.ts` line ~100:
```typescript
recentlyProcessedOrders = [...processedThisCheck, ...recentlyProcessedOrders].slice(0, 20);
// Change 20 to your preferred limit
```
